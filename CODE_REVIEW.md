# Code Review

## Summary
- **Scope reviewed:** React 18 + Vite 6 + MUI 6 SPA, PWA config, prayer/Quran/azkar/duas/ruqyah pages, sharing/bookmarks, SEO/runtime metadata, scripts, and deployment artifacts.
- **Validation executed:** `npx tsc --noEmit`, `npm test` (prayer/events/share/content), `node scripts/smoke-test.mjs --fast` (35/35), `npm run build`, `npm run verify`.
- **Overall assessment:** solid content/data structure and good offline-first direction, but several correctness, UX, and deployment issues were present. The highest-value low-risk fixes were implemented in this pass.

## Notes
- **No invented religious content:** only structural/data-integrity checks were added (`scripts/content-test.mjs`: 114 surahs, 6236 ayat, sequential numbering, non-empty text, basic azkar/duas/ruqyah shape).
- **Preserved architecture:** React Router SPA retained; static per-route HTML shells added for crawler metadata instead of SSR migration.
- **Deployment:** added `wrangler.jsonc` + `worker/index.js` for Cloudflare static assets with security/cache headers and `404` handling; removed dependence on `_redirects`.
