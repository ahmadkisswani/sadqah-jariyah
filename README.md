# صدقة جارية

موقع إسلامي بسيط ومُحسَّن للعمل على الويب، هادئ وسريع، يُعرض فقط لأجل الأجر، مكرَّس لروح:

- توبة عبد العزيز الجربوعه
- محمد احمد مسلم

نسأل الله أن يتقبل هذا العمل ويجعله صدقةً جاريةً عنهما، وينفع كل من قرأ أو ذكر أو دعا.

## الهدف

"صدقة جارية" هو موقع خالٍ من الإعلانات والتعقيد، يجمع بين قراءة القرآن الكريم، الأذكار، الأدعية، التسبيح، والرقية الشرعية، مع مواقيت الصلاة واتجاه القبلة والمساجد القريبة والتقويم الهجري، ويعمل دون اتصال (تعمل معظم الأقسام offline، أما التلاوة الصوتية وبلاطات الخريطة فمن الإنترنت فقط).

**🔗 رابط تجريبي مباشر (Demo):** <https://sadqah-jariyah.ahmadkisswanisite.workers.dev/>

## التقنية

- [Vite](https://vitejs.dev/) + [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) (كتابة خفيفة)
- [MUI 6](https://mui.com/) مع الثيم الداخلي، ألوان هادئة وعرض RTL
- [React Router 6](https://reactrouter.com/)
- [vite-plugin-pwa](https://vite-pwa-org.netlify.app/) لتثبيت الموقع والعمل دون اتصال
- [Fontsource](https://fontsource.org/) — خطوط Amiri (للقرآن)، Noto Naskh Arabic، Noto Sans Arabic
- [AlAdhan API](https://aladhan.com/prayer-times-api) — مواقيت الصلاة (بلا مفاتيح ولا حساب)
- [OpenStreetMap](https://www.openstreetmap.org/) + [Overpass API](https://overpass-api.de/) — بيانات المساجد القريبة (رخصة ODbL)
- [Leaflet](https://leafletjs.com/) — خريطة المساجد، تُحمّل عند الطلب فقط
- `Intl.DateTimeFormat` بتقويم `islamic-umalqura` — تحويل هجري محلي بلا شبكة
- [BigDataCloud](https://www.bigdatacloud.com/) — ترجمة الإحداثيات إلى اسم مدينة/دولة (خدمة مجانية بلا مفاتيح)
- LocalStorage فقط، لا Firebase/Backend/تسجيل دخول، لا إعلانات، لا تتبّع

## مواقيت الصلاة (كيف تعمل)

- **المصدر:** مواقيت الصلاة تُطلب من خدمة [AlAdhan](https://aladhan.com/prayer-times-api) مباشرة من المتصفح، بلا قيم ثابتة ولا مفاتيح، وتُطلب بصيغة ISO8601 مع إزاحة المنطقة الزمنية، فالعدّ التنازلي مبني على **لحظات مطلقة** (`Date.parse` مقابل ساعة المتصفح) ولا يتأثر بالتوقيت الصيفي. التقويم الشهري داخل صفحة المواقيت يأتي من تقويم الخدمة، أما صفحة التقويم الهجري المستقلة فتحوّل محليًا عبر `Intl`.
- **الموقع:** إذن الموقع يُطلب بلطف (مرة واحدة بضغطة صريحة)، وإن رُفض أو تعذّر نعرض مواقيت تقريبية حسب الشبكة، مع إمكانية اختيار الدولة/المدينة يدويًا أو إدخال الإحداثيات. الموقع يُحفظ في هذا الجهاز فقط ولا يُرسل إلى أي خادم لنا.
  - **على iPhone:** تحديد الموقع يحتاج فتح الموقع باتصال آمن (https)، وإن كان الإذن مرفوضًا فالمسار: الإعدادات ← الخصوصية والأمان ← خدمة الموقع ← المواقع في Safari ← «أثناء استخدام التطبيق» ثم إعادة المحاولة. وإن تعذّر GPS نعرض مواقيت تقريبية حسب الشبكة مع تنبيه واضح واختيار يدوي للمدينة.
- **طريقة الحساب:** تلقائية حسب الدولة (الأوقاف الأردنية للأردن، أم القرى للسعودية، الهيئة المصرية لمصر، ISNA لأمريكا… إلخ)، ويمكن تغييرها يدويًا مع إظهار الطريقة المستخدمة فعلًا في الصفحة. مذهب العصر (الشافعي/الحنفي) وقاعدة خطوط العرض العالية قابلان للتغيير أيضًا.
- **التقويم والمناسبات:** التقويم الشهري وتفاصيل كل يوم (هجري + مناسبات) من تقويم الخدمة نفسه، مع عدّاد رمضان (السحور والإفطار) والعيدين. أما صفحة [`/hijri-calendar`](https://sadqah-jariyah.ahmadkisswanisite.workers.dev/hijri-calendar) فتحوّل التواريخ محليًا عبر تقويم أم القرى، مع إزاحة ±يومين لمراعاة اختلاف بداية الشهر. وقد تختلف التواريخ الهجرية حسب الدولة ورؤية الهلال.
- **شرح المواقيت والتذكير:** بطاقة «عن هذه المواقيت» توضّح أن الأوقات محسوبة فلكيًا وليست أذان المسجد، وتعرض المنطقة الزمنية وطريقة الحساب وحالة البيانات. ويمكن تفعيل تذكير محلي اختياري قبل الأذان (٠/٥/١٠/١٥ دقيقة) بعد منح إذن الإشعارات؛ لا يُطلب الإذن تلقائيًا، ولا يعمل التذكير إذا أُغلق الموقع، ولا يوجد خادم إشعارات.
- **التخزين والأداء:** مواقيت اليوم تُحفظ محليًا (٦ ساعات)، والشهر سبعة أيام؛ ولا يُعاد أي طلب في العدّ التنازلي، والعدّ يجري محليًا كل ثانية. الصفحة تُحمّل كسولًا (chunk مستقل)، وصفحات القبلة والمساجد والتقويم الهجري تُحمّل عند فتحها فقط.
- **عند تعذّر الخدمة:** تُعرض رسالة واضحة («مواقيت الصلاة غير متاحة مؤقتًا») مع زر إعادة المحاولة، وإن وُجدت بيانات محفوظة سابقة تُعرض مع تنبيه — ولا تُعرض أبدًا أوقات وهمية.

## النشر على Cloudflare (Workers / Pages)

- **رابط النشر الحالي (Demo):** <https://sadqah-jariyah.ahmadkisswanisite.workers.dev/>
- Cloudflare Pages: Framework preset = Vite، Build command = `npm run build`، Output directory = `dist`
- Cloudflare Workers: `npx wrangler deploy` مع توجيه الأصول الثابتة من `dist`
- لا حاجة لملف `_redirects` مع Workers؛ الخادم يتعامل مع مسارات SPA.

## التشغيل محليًا

```bash
npm install
npm run dev
npm run build
npm run preview
npm run verify        # التحقق من مخرجات البناء
npm test              # كل اختبارات المنطق (مواقيت، مناسبات، مشاركة، محتوى، موجة أولى)
npm run test:phase2   # منطق القبلة والتقويم الهجري والمساجد
node scripts/smoke-test.mjs --fast   # اختبار دخاني حقيقي على نسخة dist
node scripts/smoke-test.mjs --url https://sadqah-jariyah.ahmadkisswanisite.workers.dev --fast --live-mosques   # بحث مساجد حقيقي بلا محاكاة
```

> على Windows، قد يفشل `npm run smoke` أو `npm run preview` بخطأ `EUNKNOWNCONFIG`؛ استخدم الأمر المباشر أعلاه بعد `npm run build`.

## ملاحظات

- النص القرآني مُضمَّن محليًا بالكامل (١١٤ سورة)؛ يعمل دون اتصال بعد الزيارة الأولى. التلاوة الصوتية تتطلب اتصالًا بالإنترنت.
- العرض الافتراضي للقرآن هو **صفحات مصحف المدينة** (١..٦٠٤) كما في المصحف: ترويسة بالجزء واسم السورة ورقم الصفحة، ونص متصل مضبوط، وعلامة دائرة لرقم كل آية. ويمكن التبديل إلى "متصل" (السورة كاملة في صفحة واحدة) أو "بطاقات".
- التلاوة تعمل آية بآية على iOS Safari وAndroid: عند لمس رقم الآية يبدأ التشغيل ويتابع تلقائيًا حتى نهاية السورة، مع شريط سفلي للتحكم واختيار القارئ ومشغّل نظام بديل عند الحاجة.
- البحث في القرآن يعتمد على فهرس السور. حجم الخط قابل للتعديل.
- المواقيت تقريبية بطبيعتها الحسابية وقد تختلف قليلًا عن مسجدك (لكل مسجد معاييره وتعديلاته)، وتُعرض طريقة الحساب المستخدمة دائمًا في الصفحة.
- بيانات المساجد من OpenStreetMap برخصة ODbL، والتغطية تطوعية وقد لا تشمل كل مسجد. البحث لا يبدأ تلقائيًا، ولا يُحفظ سجل بحث زمني. يمرّ البحث عبر عامل الموقع في Cloudflare (لتفادي حجب شبكات المستخدم لخدمات Overpass) مع مصدر بديل لنفس بيانات OSM، ولا يُخزَّن على الخادم أي إحداثي.
- شريط التنقل على سطح المكتب يعرض الأقسام الأساسية في صف واحد، وبقية الأقسام والمحفوظات داخل قائمة «المزيد» لتجنّب الازدحام.
- اتجاه القبلة يُحسب محليًا، ولا تُحفظ قراءات البوصلة أو سجل حركة. الدرجة الرقمية تشير إلى الشمال الحقيقي، والبوصلة مساعدة بصرية تعتمد على حساس الجهاز.
- جميع التقدّم (الأذكار، التسبيح، المحفوظات، ورد اليوم، التفضيلات، الموقع، إعدادات التذكير والإزاحة الهجرية) يُحفظ محليًا فقط.
